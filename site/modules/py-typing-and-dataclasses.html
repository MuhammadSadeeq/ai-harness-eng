Hints are notes next to names

A type hint is a note that says what type a name should hold. In this function the parameters are annotated as int, and -> int says what it returns.

def add(a: int, b: int) -> int:
    return a + b


total: int = add(2, 3)
print(total)
5

Run the code with the Run key. The output is 5, the sum of the two numbers.

A hint can allow more than one type. int | None means the value is an int or None.

def label(count: int | None) -> str:
    if count is None:
        return "none"
    return str(count)


print(label(None))
print(label(3))
none
3

Without JavaScript, the question is: what does this hint allow? def label(count: int | None) -> str

  1. Only an int
  2. An int, or None
  3. Any value at all
  4. A string

The next call does not match its hints. The hints say int, but the call passes two strings.

def add(a: int, b: int) -> int:
    return a + b


print(add("2", "3"))
23

The code runs and prints 23. The hints say int, and nothing stopped the call.

A record with named fields

A dataclass is a class that holds named fields. Each field has a name and a type. A field can have a default, which is used when you leave it out.

from dataclasses import dataclass


@dataclass
class Task:
    title: str
    done: bool = False


task = Task("write the test")
print(task.title, task.done)
write the test False

The title field has no default, so you pass it. The done field has a default of False, so you may leave it out.

import inspect
from dataclasses import dataclass


@dataclass
class Task:
    title: str
    done: bool = False


print(inspect.signature(Task))
(title: str, done: bool = False) -> None

Task has no __init__ method in its code. inspect.signature still shows the parameters a call takes: the two fields, with the default.

Without JavaScript, the question is: the snippet makes task = Task('write the test'). What does task.done hold?

  1. An error, because done is required
  2. False
  3. None
  4. An empty string

Keep it

Types are documentation the checker reads.

What does int | None mean in a hint?
The value is an int, or None.
What is a dataclass?
A class that holds named fields.
Must you pass a field that has a default?
No. Leave it out and the default is used.
What do you run to check the hints in your file?
mypy, on your own machine.
