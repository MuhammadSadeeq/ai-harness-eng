Lab · build Rein

Build Rein, one step at a time

Each step adds a few lines to one file, runs it, and shows what to try next.

Step 1

Send one message to a model and print its reply, with a scripted model and a real one behind the same interface.

rein.py starts at 105 lines.

python rein.py "Say hello" --fake scenarios/01_hello.json

You should see exactly this:

you      Say hello
model    Hello! I am a scripted stand-in for Claude. I say what my script says.
         stop_reason=end_turn tokens_in=10 tokens_out=25

Step 2

Give the model one tool, and a loop that keeps calling the model until it stops asking for tools.

rein.py grows to 172 lines.

python rein.py "Find the bug in demo/calc.py" --fake scenarios/02_read.json

You should see exactly this:

task     Find the bug in demo/calc.py
turn 1   model: I will read the code first.
         tool   read_file {"path": "demo/calc.py"}
         result def add(a, b): | return a - b
turn 2   model: Now the test.
         tool   read_file {"path": "demo/test_calc.py"}
         result from calc import add | def test_add(): | result = add(2, 3) | assert result == 5, f"
turn 3   model: Found it: add() returns a - b, but the test expects a + b. I can only read, so I can
done     after 3 model calls
