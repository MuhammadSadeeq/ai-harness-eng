Give the loop a second exit

Write the code, then run the tests. The tests are the judge; the reference solution is there for comparison.

Practice

The starter code for this kata. It fails the tests until a limit is added. With JavaScript on, you can run it here.

def run_turns(step, max_turns):
    """Call step() until it returns "done", then return "done".

    Add a second exit: after max_turns calls without "done", return "max_turns".
    """
    while True:
        if step() == "done":
            return "done"
