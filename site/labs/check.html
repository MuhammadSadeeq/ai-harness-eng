Predict the spiral

Will a turn limit of 12 change how many runs pass?

  • Yes. Runs that hit the limit fail, so fewer runs pass.
  • No. The same runs pass, and the runs that loop stop sooner and cost less.
  • Yes, and the new board passes every run, because the model has to finish.

On the same 20 seeds, the new board passes 13 runs and the old board passes 13 runs. The worst case goes from 60 turns to 12 turns, and from ≈ $0.3988 to ≈ $0.0264.

Predict the false done

Which board ends more runs with a false done?

  • The old board. Its runs say done, nothing checks the claim, and the harness takes the word.
  • The new board. The verify gate adds more ways for a run to end wrong.
  • Neither. A false done needs a model that lies.

On the same 20 seeds, the new board passes 20 runs and the old board passes 13 runs. The worst case goes from 3 turns to 6 turns, and from ≈ $0.0039 to ≈ $0.0093.

Which wire

A turn limit stops a run before the next model call. Which wire is it on?

  • Control plane: it shapes the prompt the model sees.
  • Loop and state: a guard that runs before each turn.
  • Permissions: it decides which tools may run.
  • Verification: it checks the work when the model says done.
