A

agent loop

The code that calls the model, runs the tools the model asks for, adds the results to the history, and calls the model again. It stops when one of its exits is taken.

Loop Taught in B2 · The agent loop

Also written: agent loops

D

dataclass

A Python class that holds named fields. The @dataclass decorator writes the __init__ method, so Rein can build a reply with named fields.

Loop Taught in H1 · Rein 1: talk to a model

Also written: dataclasses

done claim

The model's own statement that it has finished, carried by end_turn. The loop treats it as a claim to check. It is not proof that the task is done.

Loop Taught in B2 · The agent loop

Also written: done claims

E

exit

A reason the loop stops. A loop with one exit stops only when that one exit is taken.

Loop Taught in B2 · The agent loop

Also written: exits

M

model interface

One function that Rein calls to get a reply. A scripted model and a real model both sit behind it, with the same inputs and the same kind of result.

Loop Taught in H1 · Rein 1: talk to a model

Also written: model interfaces

R

ReAct

A name for the loop of reasoning and acting in turns, from the paper ReAct: Synergizing Reasoning and Acting in Language Models.

Loop Taught in B2 · The agent loop

T

token budget

A cap on the total tokens a run may use, input and output together. The loop checks it before each call and stops when the total has reached the cap.

Loop Taught in B2 · The agent loop

Also written: token budgets

tool registry

A table from each tool name to the Python function that runs it. The loop looks up the name the model asked for. A name that is not in the table gets an error result.

Tools Taught in H2 · Rein 2: one tool and the loop

Also written: tool registries

turn

One call to the model and the tool results that follow it. A run is a series of turns.

Loop Taught in B2 · The agent loop

Also written: turns

turn limit

A cap on the number of model calls in one run. When the count reaches it, the loop stops.

Loop Taught in B2 · The agent loop

Also written: turn limits
